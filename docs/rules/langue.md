# Langue

Tout ce que ce dépôt produit à destination d'un lecteur s'écrit en **français** :
messages de commit, documentation, libellés de l'interface, noms de tests et messages
d'assertion.

Le code lui-même reste en anglais — noms de variables, de fonctions, de composants et
de fichiers — comme c'est déjà le cas dans `src/`.

Les termes techniques sans équivalent français courant (commit, build, hook, lint,
pull request) s'emploient tels quels dans un texte français.
